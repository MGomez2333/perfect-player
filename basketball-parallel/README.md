# 篮球平行时空 · 独立网页版本

游戏：[直接游玩](https://mgomez2333.github.io/perfect-player/basketball-parallel/)

原页面：https://activity-static.hupu.com/shaper/published/app_293f0a2d1c/index.html?night=0

保留王朝模式、普通球员生涯、棱彩生涯。回到一场球、我的梦之队、他化自在仅保留入口。奖励视频统一直接返回成功，再由原游戏奖励事务发奖；不请求广告 SDK。

界面和王朝模拟使用下载的原页面与模块。生涯的原服务器接口未公开，改用 `local-runtime.js` 本地模拟，保留抽取十三项能力、常规赛、季后赛、成长、合同及天赋流程。生涯服务器数值算法不声称与原版一致。虎扑账号、社区与跨用户云排行榜没有接入。本机存档使用浏览器存储，清理站点数据会删除进度。

4,476 个原图片与字体资源由 `build.py` 保存到同源路径，资产清单见 `asset-manifest.json`。部分编码数据在运行时生成旧图片网址，本地适配器同时处理普通 DOM 与 Shadow DOM 图片，将其映射到已缓存资源。

验证：王朝球队创建、阵容头像、单场模拟；普通生涯十三项能力组装、免费换队次数增加、赛季播报；本地引擎确定性、82 场记录、比分与个人数据一致性、天赋加成、奖励五人抽取、年龄成长。

## 生涯数据规则（2026-10-09）

普通生涯与棱彩生涯使用相同的位置与能力规则。位置影响篮板和助攻机会，不设后卫篮板或内线助攻的固定上限。篮板综合篮板能力、力量与运动能力；助攻综合传球、控球与关键球能力。上场时间影响产量，高能力区间的收益增强，天赋超过 99 的能力仍有收益。每场比赛保留随机波动，常规赛与季后赛均应用这些规则。

新规则用于之后发起的赛季模拟；已生成的比赛和既有生涯统计保留原结果，刷新页面不会重算历史成绩。王朝模式仍使用原版独立引擎。

运行 `node basketball-parallel/tests/career-balance.cjs` 可检查五个位置的常规能力表现、顶级后卫篮板、组织内线助攻、专项能力与辅助能力的作用、天赋收益、含年龄衰减的长期纪录路径、确定性以及投篮数据一致性。测试属于本地算法验证，不代表每个玩家的实际生涯都能破纪录。

## 生涯修复（career-v3）

单场队友数据为整数，全队得分与比分相符、双方各240分钟。合同带阵容、年龄、OVR、本地模拟合同与球队前景。新奥尔良球队使用统一身份、按赛季显示黄蜂/鹈鹕，与夏洛特分开；旧合同缺失阵容和误标留队会修复。

抢断、封盖综合防守、运动能力与位置，最佳防守阵容和DPOY将用户纳入统一排名。自建球员姓名按生涯保存。确认的海克斯永久保存、多张累积，条件效果在适用场景触发，长青减少年龄衰减，名师与收割者保留获取衣钵条件。未知旧海克斯无法凭空恢复。

主页成就入口加入单场纪录、累计纪录、两双/三双/四双/五双/5×5。常规赛与季后赛分开，已观看比赛与赛季结算按同一生涯和赛季更新，刷新不累加。记录参照来源见 records.json。旧存档恢复已保存的总量与最高，未保存的多双次数不追溯。极限表现需极高的多项能力，并且概率很低；不使用无法突破的位置硬上限。

验证：`node basketball-parallel/tests/career-features.cjs` 与 `node basketball-parallel/tests/career-balance.cjs`。

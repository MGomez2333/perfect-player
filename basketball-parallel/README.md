# 篮球平行时空 · 独立网页版本

游戏：[直接游玩](https://mgomez2333.github.io/perfect-player/basketball-parallel/)

原页面：https://activity-static.hupu.com/shaper/published/app_293f0a2d1c/index.html?night=0

保留王朝模式、普通球员生涯、棱彩生涯。回到一场球、我的梦之队、他化自在仅保留入口。奖励视频统一直接返回成功，再由原游戏奖励事务发奖；不请求广告 SDK。

界面和王朝模拟使用下载的原页面与模块。生涯的原服务器接口未公开，改用 `local-runtime.js` 本地模拟，保留抽取十三项能力、常规赛、季后赛、成长、合同及天赋流程。生涯服务器数值算法不声称与原版一致。虎扑账号、社区与跨用户云排行榜没有接入。本机存档使用浏览器存储，清理站点数据会删除进度。

4,476 个原图片与字体资源由 `build.py` 保存到同源路径，资产清单见 `asset-manifest.json`。部分编码数据在运行时生成旧图片网址，本地适配器同时处理普通 DOM 与 Shadow DOM 图片，将其映射到已缓存资源。

验证：王朝球队创建、阵容头像、单场模拟；普通生涯十三项能力组装、免费换队次数增加、赛季播报；本地引擎确定性、82 场记录、比分与个人数据一致性、天赋加成、奖励五人抽取、年龄成长。
